# 静态三维点云模型：第一阶段

用途：验证原深度、内参、采集时刻完整位姿和电脑端融合链路。只是局部静态点云模型，不是整屋SLAM、连续表面网格或已标定测量仪。

## 启动

在本项目目录运行`python -B tools/reconstruction_server.py`，打开http://127.0.0.1:8766/。电脑需要NumPy，机器人使用现有ROS Galactic和相机输出；不另开设备驱动，不修改相机标定。SSH使用本机被Git排除的config/readonly_ssh_config。

网页点击“采集30秒静态模型”，或显式使用`python -B tools/reconstruction_server.py --capture-seconds 30`启动一次有界采集。原导航服务继续在8765运行，主导航页新增“静态3D建模”链接，刷新即可看到，不需要重启它。

保持机器狗和被测场景静止。每次点击采集会创建新模型；上次结果已保存在本机evidence/reconstruction/会话目录。不要把“停止本次采集”当作机器狗急停，它只终止本页的SSH订阅，不影响手机、建图或导航任务。程序不发布运动，也不启动原厂任务。

## 数据处理

机器人约每秒取3帧原深度，通过最多6帧队列等待原时间戳TF，最长2秒后丢弃，绝不套用最新TF。传回压缩深度、内参和vodom到相机的完整位姿；电脑以stride4反投影、筛选0.15—4m深度，按1cm体素平均融合，至少两帧观测支持才显示模型点。这里的采样范围和体素分辨率不是相机量程或精度保证。

检测到相机相对首帧位姿变化超过3cm或5度，停止本次融合。传感器断流、坐标改变、畸形数据或容量200000体素上限也不会被当作有效模型继续叠加。位姿门限只用于当前静态试验，不适用于移动扫描或房间级重建。

网页拖动旋转、滚轮缩放，支持适配模型、水平视角、XY俯视和PLY导出。网格用于观察，不代表已标定的真实地板；颜色按几何高度生成，不是RGB纹理。显示最多约30000个抽样点，PLY保存所有达到重复观测要求的体素中心。

蓝色狗头表示首帧相机光学原点，蓝色箭头按该帧完整四元数的光学+Z方向计算，表示相机朝前。它是采集时的方向参照，不是鼻尖精确位置、机身轮廓或实时头部关节姿态。缺少对应会话/坐标的位姿时不显示猜测箭头。适配视野同时包含模型、狗头和箭头端点。

只查看最近一次已保存结果，可使用`python -X utf8 -B tools/reconstruction_server.py --restore-latest`。此选项只读取本机模型与首帧位姿，不连接机器人。恢复后显示的是PLY中的稳定点，原始体素累计权重不恢复；点击开始采集仍会创建全新模型，不继续把新帧写入历史模型。

## 保存与边界

每次会话保存summary.json、逐帧统计samples.json、model.ply，以及前两帧压缩原始输入frame_01/02.json和stderr。此目录被Git排除，避免室内数据或大数据进入源码仓库；不要删除后又声称能复现全部采集。

验证分层：单元测试与格式检查→真实静态采集→与卷尺/已知尺寸对照→移动拼接。当前用户给出的鼻尖约28cm是目测值，不能用来调比例或偏移。当前16UC1毫米约定尚未通过独立尺度验收，深度偏差、姿态漂移、动态物体和反光面仍可能影响模型。

第一阶段不要求安装Open3D；先用现有NumPy验证数据链路。后续需要连续表面时再独立引入TSDF/Open3D，不应把本页点云输出称作已经完成的网格重建。
