# 目标范围扫描与视角操作

- 8766采集页新增默认勾选的“仅保留中心目标”，X/Y/Z为vodom坐标轴方向的固定长方体尺寸，单位米。初始值1×1×1.2米。
- 开始前目标实体需要位于深度画面中央。首帧中央11×11像素有效深度的中位数确定一个目标表面参考点，转换到vodom后固定为范围中心。它不是物体几何中心或自动语义识别。
- 后续每帧按自身完整位姿转换到同一vodom，范围外深度置零后再融合和归档。范围内背景仍可能留下，过小范围可能截断目标背面；应覆盖整个物体尺寸并预留深度。失去目标有效深度时采集会停止，建议始终面向目标。
- 此功能用于新的采集，旧294帧结果不自动猜测目标位置或修改。
- 8768离线页新增初始方向、俯视、正视、侧视；双击可见模型点/表面将旋转中心移到命中处。左键旋转、右键平移、滚轮缩放。初始方向为固定局部坐标视角，不代表真实房间北向。
- 8766也新增初始方向按钮。刷新网页可加载最新页面；目标裁剪后端需新版服务。

验证：目标框尺寸检查、范围外深度裁剪、相机移动时世界中心不变与服务测试共16项通过；浏览器四个方向按钮和双击操作执行无脚本错误。未自动发起新实机扫描。
