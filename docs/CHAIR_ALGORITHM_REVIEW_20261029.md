# 椅子点云形状修复选型

日期：2026-10-29。仅研究与选型，以下方法尚未作为新算法通过本项目数据验收。

## 判断

已有观测的毛刺、错位、重复厚层可通过算法改善。孔洞应先检查其他视角是否有数据，不能由一帧缺失推断全部缺失。
如果所有视角均无观测，只能采用带假设的表面补全，或补采；补全表面须区别于实测表面。
目前整圈灰模仍沿用原位姿；已有的局部 ICP 候选不等于联合优化后的完整轨迹。
2 米近景版减少远处不稳定数据，但不能代替位姿优化和物体表面重建。

## 开源方法及适配

| 路线 | 解决什么 | 本项目决定与边界 |
| --- | --- | --- |
| Open3D 分段配准、位姿图联合优化、重新积分 | 多视角错位、重复层、累计漂移 | 优先；以现有深度和原位姿初值改造几何配准，不宣称完整RGB-D流程可直接运行，归档没有同步RGB |
| PCL MLS局部曲面拟合 | 已对齐点云的小尺度粗糙、法向不稳定 | 优先作离线对照；按局部尺度处理，保留细支架/锐边，不能用大邻域把扶手与椅背抹成一团 |
| Open3D Screened Poisson/球旋转等表面重建 | 从有法向的点云生成连续曲面 | 作为独立候选，与现有TSDF比较；Poisson可能在无观测区外推，必须检查低密度区域及真实空隙 |
| 深度保边空间滤波、运动补偿后的时序一致性 | 融合前减轻深度噪声 | 可借鉴librealsense方法思想；尚未确认本机传感器型号，不套用D400专属视差参数，不直接跨移动帧逐像素平均 |
| PIN-SLAM隐式神经建图 | 联合建图、位姿与表面表达 | 备选；官方有RGB-D扩展，Windows推荐路径与GPU环境需另行适配，现有自定义归档也需转换，当前不作为最快落地方案 |
| 按椅子类别进行结构拟合/学习补全 | 借助先验得到更规整的椅面、支架 | 若后续采用，明确显示为拟合/推断，不能当作缺失部分已被测量；目前没有实现 |

## 推荐执行顺序

1. 从已有331帧中选同一区域、重叠充分的少量视角，先验证椅背和支架局部对齐；保留用于独立检查的视角。
2. 对通过检查的约束建立联合优化；错误边不能为维持连续而强行加入。优化后重新投影回原深度检查，再积分。
3. 在已对齐点云上比较保边平滑/MLS，依据细支架的直径、位置和空隙是否保留判断效果。
4. 对比更细尺度TSDF与Poisson等网格方法，明确完整性与外推区域。现有2厘米体素对细框架可能过粗，需要局部试验，不先许诺1厘米必然成功。
5. 只有在已有帧仍不能提供有效座面观测时再补采相应视角。

验收不能只看面数或配准通过数：同一区域、同一视角并排查看；验证帧的重投影误差及覆盖；椅背/扶手/支架相对位置、厚度与空隙；缺失和推断区域标记；实际尺寸另需尺量。
