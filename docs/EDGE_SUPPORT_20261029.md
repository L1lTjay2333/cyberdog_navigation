# 多视角边缘确认实验

入口：http://127.0.0.1:8769/edge_support/ 。可在同一视角切换原始融合灰模和实验灰模，并叠加橙色待确认边缘抽样。主工作台8768不替换。

## 方法与限制

处理已有331帧：沿用空间异常剔除和原始位姿，非边缘像素保持不变。对深度突变/无效邻域边缘点，以完整相机位姿投影到前后各最多2帧、时间差不超过1秒的有效深度中。至少两帧在`0.015+0.005*z`米实验容差内支持，且无自由空间冲突，才进入实验融合层。

观测到的更近表面视为遮挡、不给否定票；预测点在已观测表面前方的自由空间内，视为冲突。出视野、无效深度不提供支持。重复时间戳不能重复计票。相近时间戳不是独立精度真值，该容差也不是相机标定精度。

无法确认的边缘仍存在于原始归档，并输出确定性的抽样点云供查看，不能统称噪声。实验使用现有位姿，因此真实边缘也可能因位姿误差无法确认。尚未加入TSDF逐像素软权重，不能称为已完成置信加权融合。
