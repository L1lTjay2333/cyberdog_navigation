## 静态中央区域重复性

用户提供鼻尖到平面“约28cm”，明确无卷尺，仅为目测值。相机光学原点、鼻尖及base_link原点不同；不得计算所谓2.5cm标定误差，不得按目测值调整比例或偏移。

十二秒采集中取中央20%图像区域，31帧成功用于统计：

| 指标 | 本次观测 |
|---|---|
| 帧内中央光学Z中位数的范围 | 0.304—0.305m |
| 上述跨帧中位数的标准差 | 约0.000368m |
| 中央平面全部采样点绝对残差P95的跨帧中位数 | 约0.001057m |
| 平面拟合保留比例 | 约89.7% |

这些是当前局部表面与短时间窗口的重复性/平面一致性，不是绝对测量准确度，更不证明房间尺度、全视场或移动拼接达到毫米级。里程计不能独立排除物理搬动。中央区域目标身份与实际平面需现场确认。

临时探针采用原有16UC1毫米/32FC1米的驱动约定，尚未独立验证尺度。一个候选样本因深度与CameraInfo时间不匹配被拒绝，没有将失败样本伪造成有效值。

相机光学系到base_link的TF平移为[0.26932,0,0.11543]m，含旋转；不能直接把光学Z、机身X、平面法向距离及鼻尖净距相互替代。TF给出的外参也不等于完成了物理外参标定。

## 动态TF延迟：已复现并验证的接入问题

直接取最新深度帧并仅等约0.1秒时，base_link变换可读，但vodom/map查询出现未来外推错误。示例中动态TF比所请求深度时间落后约0.32秒；laser_odom未作为独立TF坐标系发现。

临时只读探针对深度帧保留原时间戳，等待约0.65秒后再查TF：base_link、vodom、map各24次成功，0次失败。说明本窗口问题可通过等候正确时间的变换消除，不需要使用最新TF替代或伪造帧名。此结果不是任意网络条件下0.65秒永远足够的承诺。

下一步接入需要有界队列、同时间TF匹配、超时丢弃、内存上限、坐标重置分段及有效性统计。当前任务5下不能仅凭map帧存在就宣称原厂全局定位完成；初始重建应独立管理局部参考系，后续验证漂移和回环纠正。
