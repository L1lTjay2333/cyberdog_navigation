# 电脑扫描遥控台

8766扫描页已嵌入/scan-manual电脑遥控台，复用现有ManualBridge和manual_policy。无需额外启动8765导航服务。

方向控制、停止、会话所有权、输入过期、失联和传感器阻挡沿用现有实现。扫描遥控的连接按钮会重新读取相机/同时间位姿和任务状态，只有ready且原厂任务为5/code0才接管扫描遥控；随后机器人侧仍执行独立实时保护。没有自动点击连接或发送运动。

此入口允许操作者显式接管已运行扫描期间的移动，不再要求扫描一定由8765页面启动。它不能用于同时接管到点导航。独立8765页面保持原有任务所有权规则。

扫描控制台隐藏起立/趴下按钮，空格只发停车请求，服务器未提供该台的姿态接口。W/S前后、A/D转向、J/K横移，按住操作、松开停车。键盘控制需先在遥控台内点击输入框。

停止采集与停止行走分别处理；停止采集不会自动替用户停车。停止行走使用遥控台“停止”或松键，停稳后再停止采集。所有操作均通过原厂接口，未修改机器人操作系统、运控或相机固件。

手机跳建图页发生在原厂建图任务运行期间，现有证据表明与任务切换相关，但本轮未追踪手机App界面代码，也未屏蔽手机通知。操作者可退出手机App，使用电脑页控制；不要并行使用两端发运动。
