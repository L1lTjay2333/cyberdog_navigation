# 导航页实时深度预览：离线准备

已接入navigation.html导航页，二维地图上方可见当前视野的实时深度画面，不必切换离开地图。后端复用map_stream.py独立显示线程处理最新收到的深度Image；不新增相机服务调用、任务切换或运动指令。
新增tools/depth_preview.py，支持16UC1毫米及32FC1米、大小端和行步长，缩小到最多160×120，以little-endian uint16毫米传输。仅显示0.15—4米的深度，超出范围或无返回为灰色。该范围是预览有效显示范围，不是机器人运动距离限制，也不改变原始采集。
新增depth_live.js近暖远冷显示、有效像素比例、帧新鲜度。两秒未收到新鲜深度即清灰提示；即使导航状态轮询停止，独立浏览器定时器也检查过期。深度值为相机光轴Z，不是机身净距。离线回放明确标示，不能作为实机连通证明。
原有点云与导航控制逻辑保持独立；只显示当前相机视野，不声称完成全房间高精度三维地图。真实导航期间是否持续发布深度图、是否共用相机资源，尚待实测。
