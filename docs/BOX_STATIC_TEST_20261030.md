# 地面黑色箱体试采

用户提供现场照片后执行16秒静止采集，记录位于 `evidence/rgbd_samples/20261030_173035_708434/`。保存4对彩色/深度，4份深度点云，未发送运动命令。
前景轮廓诊断输出在 `projection_foreground_check/`。

实际机器人彩色照片显示大部分画面为天花板、隔板和房间背景，地面箱子仅顶部出现在画面底部，被下边界裁断。深度边界诊断可见箱体形状区域。因此不能用外部手机照片中“整个箱子都在狗前方”推断两个相机都看到了完整箱体。
本轮结论为共同视野不足，未进行箱体空间对齐验收，也未确定黑色表面就是当前阻塞原因。

下一步需要将箱体放到稳定支撑上，使其完整边界进入实际机器人彩色画面，并检查对应深度图。用户无需绕行，保持机器人静止。采集程序不提供运动控制。

## 垫高后的短时复查

记录 `evidence/rgbd_samples/20261030_173413_005969/`，6秒窗口保存1对照片/深度，消息时间戳差5.790毫秒。没有发送运动命令。
机器人彩色图中箱子顶部约在 y=410，箱体下部仍被480像素图像底边截断；深度图中能看到更完整的箱体区域。当前共同视野仍不足，不能宣布空间对齐通过。
仅增加一个低工具箱的支撑高度尚不足以让整个箱体进入彩色视野。建议下一次用稳固桌面级平台，或将哑光纸板竖直放到更高位置。先检查机器人实际图像，不能继续仅凭外部拍摄图判断覆盖。

## 再次垫高及局部检查

记录 `evidence/rgbd_samples/20261030_173707_113882/`，6秒窗口保存2对图像和2份点云。彩色箱体顶部较前次上移，底部仍被截断。
不必为了局部检查继续要求完整箱体；此前“完整箱体是必要条件”的说法过严。完整轮廓有助验收，但可见的共同边缘也可用于局部诊断。
人工查看深度诊断图后选ROI [235,100,460,315]，将有效深度邻接无效/超范围深度的边界投到照片，得到 `box_local_uncertain_boundary.png`。橙点为不确定边界，不是通过验证的实体轮廓；901个投影点保留用于诊断。
可见橙色箱体候选轮廓与照片箱体仍有偏离，不能直接用此结果修改标定，也不能宣布RGB-D配准通过。下一项需要交叉验证实际对齐计算及彩色流几何关系，用户先保持当前布置，无需继续反复垫高。
