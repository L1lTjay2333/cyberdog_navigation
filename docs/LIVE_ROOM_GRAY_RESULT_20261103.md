# 本轮实时扫描归档的离线点云与灰模

## 使用

浏览器打开 http://127.0.0.1:8772/ ，可切换灰色表面、处理后点云、原始累计点云；支持自由旋转平移缩放、俯视、下载PLY。
导航8765点云区域新增“查看本轮离线灰模 / 点云对照”链接，刷新后可见。
启动：使用 reconstruction_runtime/.venv/Scripts/python.exe 运行 tools/live_room_viewer.py。

## 数据与处理

结果目录 evidence/live_room_processed_20261103，当前是固定的离线版本，不会随随后实时采集自动改变。
处理开始时冻结两段同名建图归档的完整行，保留850个唯一时间戳帧，跨度710.23秒。源文件复制与SHA256在result.json中记录；机器人无运动请求，原归档不修改。
5厘米体素合并同帧重复点，跨帧取平均。原始累计159541点，至少3帧支持41289点；统计滤波后40170点。
主要局部平面使用RANSAC，仅将距平面不超过2厘米的已有点投影到平面，最大实测调整0.019997米。没有将所有面强制成水平/垂直，也没有强制房间或物体形状。
估计法线后用Ball Pivoting连接局部表面，删除超过20厘米边长的三角面；灰模42346面。PLY/OBJ及浏览器二进制预览已生成。
voxel_consensus.npz保留全部体素平均值及逐帧支持数；不满足重复支持的点仍保留在raw.ply供对照，不等于全部是噪声。

## 已验证与限制

浏览器实际加载并切换三种视图，无脚本错误；输出几何检查：数值有限、三角面索引合法、最大边长约束、调整上限。
视觉检查仍有孔洞、碎片、可能的重影；当前是粗略的局部环境表面模型，不是完整高精度房间。
本轮实时归档只有对齐后的世界XYZ，没有完整原始深度图、采集位姿、像素对应或彩色信息，不能直接复用RGB-D TSDF或可靠重算整圈闭环。不能从点云中位数冒充机器狗轨迹，也不能判断用户是否精确回到起点。
本处理没有修改原厂控制或位姿估计，没有进行新的机器人动作。后续改善大范围畸变，需要完善采集位姿和原始深度归档，再验证闭环配准，当前结果不宣称已去除漂移。
