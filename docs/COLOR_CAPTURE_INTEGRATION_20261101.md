# 正式扫描彩色记录接入

2026-11-01：reconstruction_capture.py新增原厂/image订阅，最多缓存30张640级照片，每秒最多保存一张与已发送深度时间差不超过50毫秒的照片。照片以color_sample存入同一深度JSON记录，保留BGR/RGB原始字节、尺寸、行跨度、独立照片时间戳。对应位姿仍为深度时刻，不冒称照片曝光时刻的位姿。

服务状态增加color_pairs。无照片、时间差过大时不算配对，网页明确显示几何对齐尚未验证。没有自动启动彩色发布服务。已运行服务需要重启才加载；本轮未发起新的机器人采集。

这次改动完成数据关联，尚未完成照片辅助几何重建。旧294帧没有对应照片，不能直接添加真实照片细节。下一步首先取得原厂实际对齐输出或通过共同可见轮廓验证内外参；在此之前不能把不同投影假设自动选为正确模型。

参考Open3D Colored point cloud registration：
https://www.open3d.org/docs/release/tutorial/pipelines/colored_pointcloud_registration.html

该算法联合几何与颜色约束，但前提是颜色已正确赋给三维点。不能把任意照片直接作为已配准彩色点云输入。最终灰模可以使用由颜色辅助得到的位姿，不要求输出纹理。

注意：空间目标裁剪作用于深度，配对照片保留完整视野；后续以标定投影做照片目标掩膜，尚未实现。30张缓存用于短时间匹配，不是全程堆积；压缩照片会增加传输和归档体积，现有归档容量限制继续生效。
