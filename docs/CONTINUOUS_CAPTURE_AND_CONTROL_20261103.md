# 持续采集与遥控改进

默认静态/移动采集由用户手动启停，seconds=0 表示持续采集；不设置倒计时和原始帧字节配额。在线模型容量与几何检查独立，触发后不结束原始归档。缺少TF或队列过期的已验证深度帧另存unposed_frames.jsonl，后续不能假设其已有空间位姿。
真实网络断开、机器人关机、磁盘写入失败仍无法保证后续帧；不会把未收到的帧宣称为完整。图像按现有采样频率采集，并非保存传感器所有原始帧率。
扫描页遥控使用独立Worker每100ms发送按住指令，最多3个并发请求、500ms请求超时；序号统一递增，旧请求不能覆盖新停车请求。页面每100ms续输入意图，超过500ms停止；后端原有心跳保护不变。焦点在同页移动不再仅因键盘输入框blur清空方向；窗口blur、切后台、松键仍停车。
43项相关Python测试通过。Worker慢响应、停车取消、输入失联、序号测试通过。无运动指令实测；现场断触改善程度需要用户下次手动遥控验证。
操作：刷新页面，选择持续采集，自己点击开始；完成后停车并手动停止采集。不会自动开启下一轮。
