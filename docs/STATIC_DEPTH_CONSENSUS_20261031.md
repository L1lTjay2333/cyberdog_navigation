# 静止点云变化与多数一致处理

用户明确指出机器人及环境静止，希望保留多数观测。选取已确认静止的隔板批次 `20261030_172452_014781`，仅在同一相机坐标系处理该批4份深度，不混合不同场景/位姿/投影分支。

## 观测

四帧共同有效像素282693。逐像素最大减最小深度中位数6毫米，95分位16毫米，约2.525%超过20毫米。仅覆盖四帧均有效的像素，不包含缺失/间歇有效像素，也不能推断世界坐标位姿是否跳变。原网页的记录选择混合不同采集批次，投影解释选择也会改变显示；它不是时间连续的点云动画。

## 新增静止离线工具

`tools/static_depth_consensus.py`：显式要求 `--static-confirmed`。检查相机topic、frame、分辨率、内参一致及时间戳唯一递增，至少3帧。
每像素从0.15–4米有效值中找最大支持的20毫米深度区间，必须获全体帧严格多数支持；输出该区间的中位深度。4帧至少3帧支持，2对2冲突留空，不生成两个表面之间的虚假中间面；无空间平滑或补洞。
20毫米为本轮诊断参数，不是传感器精度规格；移动、微动和不同距离可能需要不同处理，静止条件目前来自操作记录，不是算法自动验证。移动扫描需先做位姿对齐。

输出到该批次 `static_consensus/`，含米制深度NPY、支持数、相机坐标系PLY、报告和同一批次对照网页。保留280543像素（图像91.32%）。没有修改原始数据或标定，也尚未接入实时采集器。
相同局部ROI内，原4帧平面RMS残差为5.70–6.55毫米，多数一致结果为5.26毫米。该结果只是同批数据的局部描述，不能作为绝对精度、独立验证或完整建模通过证据。

5项测试通过：多数拒绝大离群值、2对2不造中间面、缺失不投票、薄边缘不跨像素模糊、靠后排序的主簇能胜出。离线网页5张图片已通过实际浏览器检查。

## 原因与限制

测距噪声、边缘缺失可能逐帧变化；标定/畸变模型错误、稳定空间偏差及错误世界位姿不能靠多数表决修复。该工具只缓解静止数据的非一致观测。
RealSense官方 temporal filter 同样利用逐像素历史观测改善持续性，并提示移动时可能产生拖影，适合静止场景。此工具是本项目独立多数区间规则，并非调用原厂SDK滤波器。
