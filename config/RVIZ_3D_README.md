# RViz三维显示

加载navigation_3d.rviz：包含原厂二维地图、真实深度点云、导航路径与TF，固定坐标map。该配置只有查看工具，没有导航目标或速度发布工具。需运行RViz的ROS环境实际能收到机器人domain42与相应话题；配置文件本身不建立跨网络转发。

如果暂时没有map→相机的有效TF，可将Fixed Frame改为camera_depth_optical_frame，并把点云Decay Time改为0，只看当前单帧；此时不能声称在房间坐标中完成融合。恢复map定位后再用map固定坐标。RViz自动按消息时间等待TF；不要用最新位姿强套历史深度帧。

点云Decay Time为10秒，只是可视化积累，不是永久地图保存。需要保存测量结果时，优先网页“导出PLY点云”；二维原厂地图单独保存备份。RViz对当前配置的现场接入尚未验证。
