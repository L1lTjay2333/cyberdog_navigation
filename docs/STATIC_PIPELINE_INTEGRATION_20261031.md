# 静态点云处理接入记录（2026-10-31）

## 修复内容

- 网页静态采集入口改用 ConsensusStaticModel，移动扫描仍使用原 MovingModel / StreamingModel。
- 使用每帧同时间完整位姿，将测量点重投影到首帧相机。按最近深度处理投影遮挡，不补洞。
- 有界5帧窗口，每个像素至少3帧落在同一20毫米深度区间才保留，取该簇中位数。阈值不是精度声明。
- 一致性结果重新投影成点云并做体素合并；每次替换快照，不永久累加旧毛刺。原始深度仍单独归档。
- 重复时间戳不投票；相机来源、内参或分辨率变化拒绝；间断超过2.5秒拒绝。相对首帧超过3厘米或5度时停止静态融合。
- 网页区分有效接收帧、窗口帧数、一致性更新次数及有效像素支持数。
- RGB-D采样先检查两张图都可输出，再计入配对；PC端缺少照片、有效标定点云、完整配对或时间差超过50毫秒时，不报告成功。

## 仍需验证

- 估计位姿本身若不准确，重投影仍可能出错。尚不能声明绝对尺寸精度或大角度闭环精度通过。
- 单次投影落到最近采样像素会引入离散误差；当前网页仍使用stride=4预览，不能当作完整分辨率表面。
- 20毫米一致区间、3厘米/5度限制属于初始工作参数，应以带尺寸基准的新采集验证；不为了通过而放宽。
- 彩色/深度曝光同步和原厂实际对齐输出尚未验证，本次没有自动将彩色照片用于几何优化。
- 此代码需要重新启动建模服务才会加载；旧进程与已保存旧模型不会自动变成新算法结果。
