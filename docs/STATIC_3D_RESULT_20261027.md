第二轮模型3267点全部有限；在该场景近似单平面的假设下，全部模型点的单平面绝对残差P95约3.61mm。它只是融合后几何一致性，不能称作绝对尺寸误差。此前中央区域约1.1mm残差来自更小范围和不同处理，不能直接当作同一指标比较。

用户鼻尖到平面约28cm是无卷尺的目测值；未据此修正尺度。当前仍未完成真实尺寸验收、移动扫描、闭环漂移、RGB融合或表面网格。
