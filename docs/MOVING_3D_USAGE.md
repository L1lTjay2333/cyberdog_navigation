# 小范围移动点云采集（待现场移动验收）

## 功能边界

移动模式通过原始深度采集时间的vodom完整位姿，将每帧变换到同一局部坐标，再在电脑上体素融合。它不是ICP优化、闭环SLAM或完整整屋重建，没有修正原厂里程计漂移，也没有完成绝对尺度标定。静态模式仍保留原来的3cm/5度限制，不通过放宽静态门限冒充移动模式。

本程序只订阅。不会让机器狗起立、前进、掉头或停止，不与手机抢运动控制。采集停止只能阻止继续写模型，不能让手机控制的机器狗停下。采集模式不会启动原厂建图或相机生命周期。

## 现场第一轮

1. 打开http://127.0.0.1:8766/，确认有“开始60秒移动采集”按钮。点击会建立新模型，上次模型已经保存在本机。
   前置条件：原厂深度相机正在输出，且导航页的“新场地扫描”任务已经进入5并持续发布vodom。待机101不保证有该位姿。先恢复扫描、确认有新鲜位姿，再启动独立移动采集；本页不会自动启动原厂任务。
2. 面向门框等固定目标，保持门、杂物与人员位置不动；实际走道必须可通行。先不用转向，也不用绕房间走。
3. 点击后先静止5秒。只有“有效融合帧”持续增加且没有错误，才开始人工低速移动。没有新帧就先处理采集问题，不边走边猜。
4. 用手机最低可控速度直行约半米，再松开控制停下；如果与前方目标距离不足，就缩短距离，不能为了凑半米靠近障碍。
5. 停稳再采集5秒，点击“停止本次采集”。查看门框是否出现双层或重复边缘，导出PLY。不要立刻重复扫描覆盖现场记录；先提供实际移动与页面结果。

页面蓝色狗头更新到最新**已融合帧**的相机位置，不是无延迟真实头部关节姿态；黄色线为相机轨迹。模型视野不每帧自动跳转，超出显示时点击“适配模型”。

## 限制与诊断

- 原有精确TF队列、2秒过期、无效深度和标定/坐标检查保持。
- 新位姿间隔超过2.5秒、单步超过0.2m、速度超过0.45m/s、单步旋转超过35度或角速度超过1.2rad/s，停止融合。阈值仅用于当前短距离实验，并非运动安全控制。
- 距首帧超过2m、累计相机位移超过3m或模型达到200000体素，停止并保存，避免将原型用于整屋长时漂移积累。
- 移动采集最长60秒，不自动续采或自动重试。
- 累计位移包含机身摆动和位姿噪声，不等同于卷尺行走距离。即使通过这些门限，也不能排除较慢的定位漂移或场景重影。
- 保存首两帧及每十帧一个压缩关键帧，单会话原始数据上限8MiB；每个有效帧保存相机位姿和统计，并保存轨迹与最终PLY。数据在evidence/reconstruction/，Git不上传。
- 三维模型仍是点云而非网格；1cm体素不代表1cm精度。没有卷尺时只验收拼接表现，不根据目测修改比例或偏移。

启动：`python -X utf8 -B tools/reconstruction_server.py --restore-latest`。该命令先恢复旧模型供查看，不会自动发起采集；由网页选择静态或移动。重载只影响8766，不需要重启原导航8765。

如果页面报SSH网络连接被运行环境权限拒绝，应从允许局域网访问的普通PowerShell运行服务；不要反复点采集或放宽主机身份检查。与密钥认证失败、相机未输出、同时间TF未就绪分别处理，具体证据保存在每次会话的stderr和summary中。
