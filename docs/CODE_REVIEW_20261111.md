## 优先后续优化
1. 采集融合：位姿异常帧被拒后，后续帧仍与最后接受帧比较。间隔超过2.5秒后可能持续拒绝；原始档案继续保存，但在线预览停滞。应新建待配准子图，明确显示定位中断，不把未知相对位姿强行合并。
2. 性能：/state轮询每次生成并传输最多30000点及完整轨迹。增加模型版本号与轻量状态接口，可避免相机准备检查也搬运整幅点云。
3. 共享遥控：当前同标签页跨模块共享；其他标签页控制权隔离。网页所有者租约3秒，在慢加载页面仍可能超时，须实测切页并完善会话续接，不能取消运动指令超时停车。
4. 连接和相机准备代码在两个HTML中重复，后续提取公共脚本降低修改遗漏。
5. 单帧降噪不等于绝对测距校准；整圈融合仍受位姿漂移影响。

## 本轮边界
本轮为电脑端代码与离线测试，没有进行真机动作验证；没有重启运行中的服务。
