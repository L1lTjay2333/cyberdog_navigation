# 实时点云累计与覆盖提示：首次实测

2026-11-03：网页实现已完成，尚未完成移动累计的现场验收。

## 本次改动

- 有效时间戳及 map / laser_odom 坐标对齐后，按5厘米体素累计；同帧每体素一个样本，多帧对体素内坐标加权平均，权重上限20。
- 同一传感器时间戳不重复加入。图像数据超过2秒不累计。失去坐标对齐时保留已累计模型。
- 开始新建图、订阅重连或坐标系变化时清除旧累计，避免跨坐标系拼接。
- 灰色迷雾显示尚未收到表面深度点的XY投影单元，单元25厘米；只在累计地图中显示。它不是三维占据重建，不表示未着色区域可通行，也不清除遮挡物背后的未知体积。
- 浏览器预览保留最多60000体素，超过后淘汰最早体素；不是原始扫描归档。页面刷新会丢失该预览累计，可导出PLY保留当前结果。
- 无定位时显示相机单帧，不累计；光学坐标转换为前、左、上仅用于观看和相应PLY导出。

## 已验证

tests/navigation_cloud_fusion.cjs：体素去重、跨帧累计、重复/过期帧拒绝、对齐丢失保留、迷雾开关、局部预览通过。
tests/navigation_live_views.cjs：机器人实时深度与相机点云可更新，浏览器没有脚本异常。核验时 task=101，未定位，未发送运动。

## 首次现场步骤

1. 刷新8765网页，由用户启动本轮建图或定位，手机不同时切换建图导航。
2. 保持静止，等3D状态明确显示“边走边更新”和 map/laser_odom；只显示“实时相机点云”时不能进行累计验收。
3. 面向有墙角的固定环境，人工遥控慢走约半米、缓慢转向，再回看相同墙面。
4. 检查墙面是否重合、点云是否持续累计、未知投影区是否随新观测减少。发生重影或整体错位时停止移动，保存结果后诊断位姿与时间同步。
5. 用户导出PLY；这轮验证实时拼接连续性，不以点数增加证明绝对精度或闭环质量。

## 当前限制

累计基于原厂位姿/TF，没有新增闭环优化；原厂位姿漂移仍可能使地图重影。深度缺测表面不会自动补成实体。
