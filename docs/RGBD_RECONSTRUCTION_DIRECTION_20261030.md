# 彩色照片与深度联合重建路线

## 能力判断

深度相机可用于扫描建模，但本项目尚未获得完整、可辨认椅子模型的验收结果。已有点云和灰模不能证明硬件不具备能力，也不能证明改算法一定能补齐。
当前对象含黑色座垫、反光细金属架、机器人低机位遮挡，分别存在有效深度、匹配特征和视角覆盖风险。
地面/墙体和较大哑光物体通常比该椅子更适合作为第一项重建基准；这不是要求替换用户的最终目标。

## 本机已知证据

2026-10-27日志识别为Intel RealSense D430I，见`docs/3D_PREFLIGHT_20261027.md`；本轮未连接机器人重新确认。
旧代码`tools/check_depth_sources.py`列出`camera/aligned_depth_to_extcolor/image_raw`和对应CameraInfo候选，不代表话题已激活或验证同步。
当前重建采集器只保存深度、内参、时间戳和完整位姿，没有同步RGB。现有331帧不能直接作为完整RGB-D输入。
`camera/depth/color/points`的名称也不能作为彩色图可用或点云确实含颜色的证据。

## 两条照片路线

1. **优先：机器人RGB-D联合处理。** 采集同步彩色图、深度图、两者内外参和时间戳；用图像特征及深度共同估计位姿，再联合优化与深度融合。照片参与几何估计，最终仍可输出无纹理灰模。Open3D RGB-D odometry要求颜色/深度同步并完成空间配准。
2. **补充：手机多视角摄影测量。** 使用COLMAP从重叠照片估计相机位置，再做稠密重建。手机照片与机器人深度没有天然同步和外参，须通过共同几何/控制点注册，尺度通过已知尺寸或可靠深度确定。拍摄时场景静止，不移动椅子。

照片不能确保解决黑色无纹理与反光细杆问题；仅做贴图不会修复几何。神经或类别先验补全应标明推断表面。

## 拍摄建议（待现场准备，不触发运动）

- 连续重叠视角，多拍相邻角度，避免只拍正前/正后四张；目标每部分尽量在至少3张中可见。
- 绕目标移动以产生视差，不只站在一个位置旋转相机。
- 至少覆盖低、中、较高视角。看到座面上表面才能为其提供观测；低机位绕圈不等于看到座面。
- 光照稳定、图像清晰、背景有纹理；记录一个卷尺核实的尺寸作为尺度检查。
- 机器人RGB-D先做静止同步/外参核验，再进行人工低速移动采集。现在无需开机，离线算法仍可推进。

## 本轮已做算法优化

位姿图求解后，依次检查1、1/2、1/4、1/8幅度的联合更新，阈值保持一致。检查全部候选边，通过才使用修正；所有比例失败则保留原位姿。
该步骤复用验证点来选择步幅，因此不构成独立测试集或绝对精度验证。
现有331帧中的第1–10帧，在1/2步幅、45条几何约束检查下通过。局部通过不是整圈回环通过，也不等于椅子形状已恢复。
