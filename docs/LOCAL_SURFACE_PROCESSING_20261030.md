# 局部联合配准与点云曲面处理接入

2026-10-30，新增离线工作台模式，处理电脑已有归档，不连接机器人。

## 操作

打开 http://127.0.0.1:8768/ ，选择采集记录，处理方式选“10帧局部联合对齐与曲面处理”，填起始帧，点击处理。
起始帧为1表示原归档第1–10帧。它是短片段，不是自动识别或分割椅子，也不代表完整331帧模型。
页面提供原位姿、联合对齐（通过时）、曲面处理、多帧支持灰模及下载。
对齐不通过时，曲面处理明确使用原位姿，禁用联合对齐预览及下载。

## 实现

- `tools/reconstruction_local.py`：2米深度范围，10帧全部几何边候选，已有多尺度ICP及留出点检查；连通图初始化，Open3D LM位姿图优化，重新检查相对边及5厘米/5度修正范围。全部边作为不确定约束，求解器会提示certain-edge子图不连通，此模式尚未通过真实数据轨迹验收。
- 基线与局部候选均使用1厘米TSDF，同范围、同帧数。失败候选不作为修正位姿应用。
- 在融合表面采样点上执行自实现的一阶加权局部平面MLS，3厘米邻域、最多移动5毫米；邻域不足、线状结构、非平面角点不移动。不增点、不补洞。它不是PCL绑定。
- MLS后使用球旋转重新构造网格；与基线的差异同时包含MLS与网格算法变化，不能把视觉差异全部算成MLS贡献。点云法向继承融合表面；后续若引入更大位移需重新评估法向。
- 原始档校验哈希保持；保留衍生位姿和对齐/处理报告。原始整段基础处理仍可使用。
