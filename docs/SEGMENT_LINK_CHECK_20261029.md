## 下一轮：小范围有实测尺寸的目标

1. 选不透明、哑光、有棱角的纸箱或类似物体，保持背景中有墙角等固定结构。不要只看没有纹理、没有棱角的单一平面。
2. 用尺测长宽高，记录相机与目标的实际位置。没有尺子时只能比较稳定性，不能宣称绝对尺寸准确。
3. 先检查有效深度、内参、同时间TF及任务占用，再在机器人不移动时采集基线。
4. 移动阶段由用户操控，先只做小幅平移/转向，每次停稳后保留重叠视野；不立即做整屋大幅转向。采集页面不能代替机器人停车控制。
5. 对同一数据对比原位姿、局部修正、处理后点云及灰模：核对实测尺寸、重复表面间距、重叠保留和有效覆盖。不能只看模型更光滑或面数更少。
6. 不承诺一次扫描生成物体完整背面/底部，也不把小物体演示当成整屋闭环验收。

开机后先取得当前IP进行只读接入检查，不自动触发运动或采集。该测试不会改动原厂运动控制参数。
