# 隔板静止试采

记录：`evidence/rgbd_samples/20261030_172452_014781/`。用户提供现场照片，机器人面向大面积隔板。16秒静止试采保存4对照片/深度和4份相机坐标系点云，无运动命令。

实际彩色图显示隔板占据大部分视野，深度图中有效前景跳变轮廓稀少。新投影预览位于 `projection_foreground_check/`，仍不能据此验收RGB-D空间配准。

新增 `tools/rgbd_plane_quality.py` 评估选定ROI的平面残差和静止像素深度变化。初始25%–75%高宽ROI混入隔板下方近处表面，结果不能作为隔板平整度；已保留为 `plane_quality_broad_roi_includes_floor.json`，未删除。
查看深度范围图后，选择归一化ROI [0.25,0.25,0.75,0.60]，避开下部明显深度变化区。未使用残差筛选或调节标定，结果为选定局部区域的描述：

- 深度光轴Z中位数0.823–0.824米，不等于鼻尖距离，也无卷尺真值。
- 拟合平面RMS残差5.70–6.55毫米，95%绝对残差11.09–12.75毫米。
- 四帧共同像素的逐像素最大减最小深度：中位数7毫米，95分位16毫米。
- 拟合平面垂距约0.820–0.822米，仅为传感器几何计算结果。

平面残差不是绝对测距误差，可能混合传感器噪声、表面形变与系统偏差；静止深度变化也可能含机器人微动。未做RGB-D配准通过声明。已用已知倾斜平面验证拟合残差与垂直距离计算。

下一次空间对齐验证需要在深度和彩色共同视野内看到完整的物体边界；较小的哑光纸盒/板且与背景存在深度差更合适。大隔板当前占据深度视野，不能只靠平面内部估计完整外参。
