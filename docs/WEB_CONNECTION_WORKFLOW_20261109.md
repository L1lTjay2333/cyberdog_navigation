# 网页连接与采集链路（2026-11-09）

入口：http://127.0.0.1:8765/ 。原8766入口跳转到统一工作台的/model/。

两个模块均提供IP输入与“连接SSH并准备相机”。输入IPv4，经现有SSH密钥和严格主机身份校验后，调用原厂深度相机准备与扫描位姿准备。失败时显示实际阶段，不自动启动采集或运动。IP切换在采集、遥控或任务期间被拒绝。

3D模块使用地图页面的遥控面板和manual.js；统一入口的/model/manual/*及/model/manual_state路由至地图服务同一个ManualBridge，避免两页各自持有运动会话。W/S前后、A/D转向、J/K横移，松开停车。连接按钮本身不会行走。

当前自动准备范围：深度相机和扫描位姿。彩色原生拍照仍走独立拍照入口，不能据此声称全部相机均已开启。不同相机任务的互斥需要下一轮实测验证。

离线验证：tests/connection_workflow.cjs，浏览器POST请求全部模拟，确认两页IP传递、相机准备调用、完成提示和3D六方向按钮，无运动请求。Python三个修改模块语法检查通过。
