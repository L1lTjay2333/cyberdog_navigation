# CyberDog 2 平地自主绕行导航

> 当前主工程为此仓库。下文部分状态来自2026-10-07历史记录；新版遥控和导航进展请结合后续日期文档阅读。2026-10-27开始评估深度相机三维重建，见[前置检查与精度记录](docs/3D_PREFLIGHT_20261027.md)、[论文与开源项目初筛](docs/3D_REFERENCES_20261027.md)和[改动记录](CHANGELOG.md)。本机密钥、运行配置、地图及原始证据不上传GitHub。

目标：室内平地，建立地图、选择目标点，机器人绕开可见障碍物并到达目标；无可行路线则停止。保持原厂正常行走参数，使用原厂任务管理与导航，不修改底层控制器。

## 架构与操控

深度相机及原厂里程计 → 原厂建图/定位 → 二维地图和局部障碍地图 → 原厂规划与行走。电脑负责查看地图、选择目标、显示任务状态。初次建图用手机人工行走；自主导航时由单一任务持有控制权。实际任务action类型、命名空间、传感器话题和TF必须从本机发现，不沿用历史名称。

官方依据：D:/cyberdog/参考/official_stair_research/blogs/docs/cn/algorithm_manager_cn.md。官方算法任务互斥，停止必须对应当前任务。文档入口：https://github.com/MiRoboticsLab/blogs/blob/rolling/docs/cn/algorithm_manager_cn.md。

## 复用策略

可复用点云订阅、数据解码、录制和经标定的坐标转换；逐个审查并复制，保持来源清单。相机服务须核实本机服务定义及开启/关闭语义。旧Web遥控含运动功能，不整体启动；旧楼梯几何算法、Tstair参数、USER_GAIT和库替换均不接入导航。

离线测试：PowerShell设置PYTHONPATH包含本项目src和tools，执行python -B -m unittest discover -s tests -v。机器人ROS订阅工具运行需要机器人原厂ROS环境，电脑无需为离线测试安装ROS。
